# GIF Assets

Put animated GIFs here and keep file names stable for README embeds:

- `cag-flow.gif` (full runtime flow animation)
- `cag-validate-routing.gif` (validation routing animation)
- `cag-retrieval-ladder.gif` (retrieval decision ladder)

Recommended size:
- width 1200px max
- duration 8-20s
- loop enabled

Quick capture options:
- ScreenToGif (Windows)
- OBS + ffmpeg conversion to GIF
- Peek (Linux)

README references these files with relative paths in `docs/assets/`.
